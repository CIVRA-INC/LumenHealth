# Troubleshooting

| Symptom                                                             | Cause / fix                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Could not migrate the test database. Is Postgres running?`         | `pnpm db:up`. If the Docker volume predates `init.sql`, the `lumenhealth_test`/`lumenhealth_e2e` databases or `lumen_app` role are missing: `docker compose down -v && pnpm bootstrap`, or create them with `infrastructure/docker/postgres/init.sql`. |
| `role "lumen_app" does not exist` / `permission denied for table …` | The roles are created only when the volume is first initialised. Run `init.sql` manually (`psql -U lumen -d postgres -f …`) then `pnpm db:migrate` to apply grants.                                                                                    |
| Everything returns empty lists although data exists                 | The API must connect as `lumen_app` with a tenant context. Connecting the API as the owner is not the cause; connecting with no `app.current_org_id` is. Use `PrismaService.tenant()`.                                                                 |
| `Demo data already present` but the app looks half-empty            | The database was seeded by an older, non-atomic seed that failed part-way (the seed is now one transaction, so this cannot recur). Run `pnpm db:reset` yourself (see `setup.md`).                                                                      |
| Web shows blank page after sign-in on first load                    | Vite is still pre-bundling dependencies; reload once.                                                                                                                                                                                                  |
| `EADDRINUSE` on 5173/4000                                           | Another dev server is running. Playwright uses 5174/4010 and refuses to reuse servers.                                                                                                                                                                 |
| `ERR_PNPM_IGNORED_BUILDS`                                           | A dependency wants an install script. Allow it deliberately in `pnpm-workspace.yaml` → `allowBuilds` (review why first).                                                                                                                               |
| pnpm refuses a very new package version                             | `minimumReleaseAge` protection. Pick an older version or (with care) add a `minimumReleaseAgeExclude` entry.                                                                                                                                           |
| Prisma: "invoked by Claude Code … dangerous action"                 | Prisma blocks destructive commands from AI agents; run `pnpm db:reset` yourself (try `pnpm db:reset --dry-run` first).                                                                                                                                 |
| Type errors about `@lumen/contracts`                                | Rebuild it: `pnpm build:contracts` (`pnpm dev` does this and then watches).                                                                                                                                                                            |
| Playwright cannot find Chrome                                       | Install Google Chrome, or `pnpm --filter @lumen/web exec playwright install chromium` and run with `CI=1`.                                                                                                                                             |
| Login works in the browser but API calls 403 with "Cross-origin"    | Add the web origin to `WEB_ORIGINS`.                                                                                                                                                                                                                   |
